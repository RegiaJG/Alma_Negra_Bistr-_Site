# Alma Negra Bistrô

A dark luxury restaurant website built with Next.js 14, TypeScript, and Tailwind CSS. This is a fictional brand created as part of a web design portfolio to showcase premium restaurant website templates.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Fonts:** Cormorant Garamond + DM Sans (via next/font)
- **Deploy:** Vercel (region: São Paulo)

## Features

- Parallax hero with scroll-based animations
- Interactive menu with category tabs
- Masonry photo gallery with lightbox
- Reservation form
- Fully responsive layout
- Mobile navigation menu
- Open Graph metadata for social sharing

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
